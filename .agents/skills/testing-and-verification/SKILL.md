# Verification

Use `docs/TEST_STRATEGY.md`, the active phase, and `verification-gates`. Run affected builds, tests, and an end-to-end user path when available. Record exact commands and actual results in `docs/PROGRESS.md`. Report missing tools or environments as unverified rather than passed. Do not mark a phase done while its core flow fails.
