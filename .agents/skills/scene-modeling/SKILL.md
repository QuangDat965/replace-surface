# Scene Modeling

1. Confirm world coordinate convention and stable IDs.
2. Model objects separately from selectable surfaces.
3. Store geometry, transforms, asset references, visibility and material assignment.
4. Preserve data provenance and measurement uncertainty.
5. Implement schema version validation, migration strategy and roundtrip tests.
6. Check stale scene revision conflicts.

Return relevant contract changes, verification results, and a minimal handoff checklist.
