# Verification Gates

1. Read acceptance criteria.
2. Run actual build/test commands; do not invent passing output.
3. Test UI selection, edit, undo, persistence and reload.
4. Check meter coordinates, PBR tiling, masking, IDs and asynchronous job state.
5. Verify mock result labels and remove inert controls.
6. Report witnessed evidence, errors and pending tasks clearly.

Return relevant contract changes, verification results, and a minimal handoff checklist.
